2. ИДЕЯ
================================================================================

Vortixa Drop — мобильное офлайн-приложение для быстрого принятия решений,
случайного выбора и распределения вариантов.

Пользователь добавляет собственные варианты для выбора.

Например:

• что посмотреть;

• куда пойти;

• что заказать;

• с чего начать;

• какой вариант использовать;

• какое действие выполнить;

• кого выбрать из списка;

• какие задачи выполнить первыми.

После создания набора каждый вариант получает собственное визуальное
представление в виде яркого неонового шара.

Пользователь запускает основное действие Drop.

Все созданные шары попадают в абстрактную визуальную систему Vortixa —
футуристическую воронку, через которую происходит их последовательное
движение и определение итогового результата.

После завершения процесса один шар становится выбранным.

Главная особенность приложения заключается в том, что пользователь не
использует стандартное колесо выбора, генератор случайных чисел или
обычный список.

Процесс выбора визуализирован через систему красочных неоновых шаров
и абстрактную воронку Vortixa.

Основной сценарий выглядит следующим образом:

Добавить варианты
↓
Превратить варианты в цветные шары
↓
Запустить Drop
↓
Шары проходят через Vortixa
↓
Локальный алгоритм определяет результат
↓
Выбранный шар выделяется
↓
Пользователь получает итоговое решение

Весь процесс работает локально на устройстве.

6. ОСНОВНОЙ ПРОЦЕСС ИСПОЛЬЗОВАНИЯ
================================================================================

1. Пользователь открывает приложение.

2. Создает новый набор вариантов.

3. Добавляет от 2 до 8 вариантов для быстрого выбора.

4. Каждый вариант автоматически связывается с отдельным цветным шаром.

5. При необходимости пользователь изменяет названия вариантов.

6. Пользователь запускает действие Drop.

7. Шары появляются в системе Vortixa.

8. Визуальная сцена показывает процесс движения и выбора.

9. Локальный алгоритм определяет итоговый вариант.

10. Выбранный шар остается выделенным в центральной области.

11. Пользователь видит название выбранного результата.

12. После этого пользователь может:

• повторить выбор;

• вернуться к редактированию;

• создать новый набор;

• сохранить набор;

• открыть другой сохраненный набор.

7. ОСНОВНЫЕ МЕХАНИКИ
================================================================================

VORTEX DROP

Главная механика приложения.

Пользователь добавляет варианты, после чего они превращаются в отдельные
цветные неоновые шары.

После нажатия Drop запускается визуальный процесс выбора.

Шары проходят через абстрактную систему Vortixa.

Результат определяется локальным алгоритмом случайного выбора.

Визуальное движение не влияет на математическую случайность результата,
а используется как понятное и эффектное представление процесса.

Это обеспечивает:

• честное равномерное распределение результатов;

• стабильную работу;

• отсутствие зависимости от интернет-соединения;

• визуально понятный сценарий.

-------------------------------------------------------------------------------

QUICK CHOICE

Быстрый режим для повседневного выбора.

Пользователь вводит от 2 до 8 вариантов.

После этого сразу запускает Drop.

Режим предназначен для ситуаций, когда решение нужно получить максимально
быстро.

Примеры:

• кофе или чай;

• фильм A или фильм B;

• ресторан A, B или C;

• начать с задачи A, B или C.

-------------------------------------------------------------------------------

MULTI SELECT

Режим выбора нескольких результатов.

Пользователь создает общий набор вариантов и указывает необходимое
количество результатов.

Например:

12 вариантов
↓
Необходимо выбрать 3

Приложение случайным образом определяет указанное количество уникальных
вариантов.

Один и тот же вариант не может быть выбран дважды в рамках одного запуска.

-------------------------------------------------------------------------------

SPLIT MODE

Режим случайного распределения.

Пользователь добавляет набор объектов и указывает количество групп.

Приложение распределяет объекты между группами локально.

Пример:

8 объектов
↓
2 группы
↓
4 объекта в первой группе
+
4 объекта во второй группе

При невозможности равного распределения разница между размерами групп
не превышает одного объекта.

-------------------------------------------------------------------------------

CUSTOM BALL LABELS

Каждый вариант получает:

• короткое название;

• индивидуальный цвет;

• собственный шар.

Цвета помогают быстро визуально различать варианты.

Пользователь может использовать автоматическое назначение цветов.

При необходимости цвета могут быть изменены вручную.

-------------------------------------------------------------------------------

SAVED SETS

Часто используемые наборы можно сохранить локально.

Примеры сохраненных наборов:

• фильмы;

• рестораны;

• задачи;

• упражнения;

• идеи для вечера;

• маршруты;

• варианты покупок.

Повторное использование набора не требует повторного ввода вариантов.

-------------------------------------------------------------------------------

CHOICE HISTORY

Приложение сохраняет историю предыдущих результатов локально.

Для каждого события может сохраняться:

• название набора;

• выбранный результат;

• режим выбора;

• дата и время.

История предназначена только для просмотра.

Она не требует подключения к серверу.

-------------------------------------------------------------------------------

VISUAL RESULT

После завершения процесса выбранный шар становится главным объектом сцены.

Он получает:

• центральное расположение;

• мягкое неоновое свечение;

• визуальное выделение;

• отображение связанного результата.

Пользователь сразу понимает итог выбора.

14. БАЛАНС МЕХАНИК
================================================================================

ОСНОВНОЙ БАЛАНС

Приложение не использует игровую экономику, валюту, уровни, награды или
штрафы.

Баланс построен вокруг скорости использования, количества вариантов и
понятности результата.

-------------------------------------------------------------------------------

QUICK CHOICE

Оптимальное количество вариантов:

• минимум — 2;

• стандартный диапазон — 2–8.

До 4 вариантов:

Максимально быстрый сценарий.
Подходит для простых решений.

5–8 вариантов:

Более широкий выбор.
Сохраняется хорошая читаемость цветных шаров.

Более 8 вариантов не используется в быстром режиме, чтобы не перегружать
основную визуальную сцену.

-------------------------------------------------------------------------------

MULTI SELECT

Количество выбранных результатов не может превышать количество исходных
вариантов.

Рекомендуемый диапазон:

• 2–20 исходных вариантов;

• выбор от 1 до 10 результатов.

Алгоритм работает без повторного выбора одного и того же варианта.

Пример:

10 вариантов
↓
Выбрать 3

Каждый из 10 вариантов имеет одинаковую вероятность попасть в итоговую
выборку.

-------------------------------------------------------------------------------

SPLIT MODE

Для равномерного распределения применяется следующий принцип:

Разница между количеством объектов в любых двух группах не превышает 1.

Пример:

10 объектов
↓
3 группы

Результат:

4 объекта
+
3 объекта
+
3 объекта

Это обеспечивает максимально равномерное распределение.

-------------------------------------------------------------------------------

ВЕРОЯТНОСТЬ ВЫБОРА

В стандартном режиме все варианты имеют одинаковый вес.

Для N вариантов:

Вероятность выбора каждого варианта:

1 / N

Примеры:

2 варианта — 50% / 50%.

3 варианта — приблизительно 33.33% каждый.

4 варианта — 25% каждый.

5 вариантов — 20% каждый.

8 вариантов — 12.5% каждый.

Визуальная анимация движения шаров не изменяет вероятность результата.

Это исключает визуальное преимущество определенных цветов или вариантов.

-------------------------------------------------------------------------------

СКОРОСТЬ ОСНОВНОГО СЦЕНАРИЯ

до 15–30 секунд.

сразу после завершения визуального процесса.

Повторное использование:

↓

17. УСЛОВИЯ УСПЕШНОГО ЗАВЕРШЕНИЯ ДЕЙСТВИЯ
================================================================================

Основной процесс считается успешно завершенным, если:

• создан корректный набор вариантов;

• количество вариантов соответствует требованиям выбранного режима;

• пользователь запускает действие;

• локальный алгоритм определяет результат;

• итоговый результат отображается пользователю.

Для Quick Choice:

необходимо минимум 2 варианта.

Для Multi Select:

количество запрашиваемых результатов должно быть не больше количества
доступных вариантов.

Для Split Mode:

должно быть минимум 2 объекта и минимум 2 группы.

================================================================================
18. ОШИБКИ И ОГРАНИЧЕНИЯ
================================================================================

Действие не запускается, если:

• в Quick Choice добавлен только один вариант;

• список вариантов пуст;

• в Multi Select запрошено больше результатов, чем существует вариантов;

• в Split Mode указано некорректное количество групп.

При возникновении ошибки пользователь получает краткое локальное
сообщение с объяснением причины.

После исправления данных действие может быть повторно запущено сразу.

Данные пользователя не удаляются автоматически.

19. ИТОГ
================================================================================

Vortixa Drop («Вортикса Дроп») — мобильное офлайн-приложение в категориях
Productivity, Smart Tools, Utility и Offline Tools, предназначенное для
быстрого принятия решений, случайного выбора и распределения вариантов.

Главная особенность приложения — оригинальное визуальное представление
выбора через яркие неоновые шары и футуристическую систему Vortixa.

Вместо стандартного колеса выбора пользователь добавляет собственные
варианты, превращает их в цветные визуальные объекты и запускает процесс
Drop.

Приложение локально определяет результат и наглядно выделяет выбранный
вариант.

Дополнительные режимы Multi Select и Split Mode позволяют использовать
одну и ту же концепцию для более широкого набора задач.

Полная офлайн-работа, отсутствие регистрации, локальное хранение данных,
простая структура экранов и короткий пользовательский сценарий делают
Vortixa Drop полноценным самостоятельным мобильным инструментом для iOS
и Android.

Сочетание полезной функции, нестандартного способа взаимодействия,
минималистичного UX и яркого Premium UI позволяет развивать приложение
дальше без изменения его основной концепции.
